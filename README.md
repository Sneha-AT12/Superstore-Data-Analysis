# Superstore Sales Data Analysis

## 📊 Project Overview

This project focuses on analyzing Superstore retail sales data to understand
sales performance, customer segments, regional trends, profitability,
discounts, and other business-related insights.

The project includes data collection, data cleaning, exploratory data analysis,
SQL analysis, web scraping practice, and interactive dashboard development
using Power BI.

## 🎯 Project Objective

The main objective of this project is to develop practical data analytics
skills by working with a real-world retail dataset and transforming raw data
into meaningful business insights.

The project demonstrates the complete data analysis workflow, from raw data
collection and cleaning to SQL analysis and Power BI visualization.

## 🔄 Project Workflow

1. Collected the Superstore dataset.
2. Loaded and examined the dataset.
3. Checked the dataset structure and data types.
4. Performed data cleaning and preprocessing using Python.
5. Checked data quality and removed duplicate records.
6. Prepared the cleaned dataset for analysis.
7. Performed exploratory data analysis.
8. Used Microsoft SQL Server for business-oriented queries.
9. Analyzed regional sales, segments, products, discounts, and profitability.
10. Created an interactive Power BI dashboard.
11. Used visualizations to understand business performance and trends.

## 🗄️ SQL Analysis

SQL analysis was performed using Microsoft SQL Server.

The SQL queries include:

- Creating database and tables
- Importing and working with Superstore data
- Counting total records
- Viewing sample records
- Finding distinct regions
- Region-wise sales analysis
- Segment-wise sales analysis
- Identifying loss-making sub-categories
- Filtering products based on discount
- Sorting products by sales
- Calculating average, maximum, and minimum sales
- Joining sales data with regional manager information

The SQL queries are available in:

`superstore_analysis.sql`

## 🌐 Web Scraping

Web scraping was explored as an additional data collection technique using

The scraping code is available in:

`scraping.py`

The collected data is stored separately in:
