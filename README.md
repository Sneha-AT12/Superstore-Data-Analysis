# Superstore Sales Data Analysis

## 📊 Project Overview

This project focuses on analyzing Superstore sales data to understand
sales performance, customer segments, regional trends, and business insights.

The project covers data collection, data cleaning, exploratory data analysis,
SQL-based analysis, and interactive dashboard development using Power BI.

## 🎯 Project Objective

The main objective of this project is to develop practical data analytics
skills by working with a real-world retail dataset and converting raw data
into meaningful business insights.

## 🛠️ Tools & Technologies

- Pandas

- SQL
- Microsoft SQL Server

- Data Visualization

## 📁 Project Files

| File | Description |
|------|-------------|
| `kaggle_data.csv` | Original Superstore dataset |
| `superstore_cleaned.csv` | Cleaned dataset used for analysis and dashboard |
| `scraped_data.csv` | Dataset collected separately while learning web scraping |
| `scraping.py` | Python script used for web scraping |
| `analysis.py` | Python analysis script |
| `dash.pbix` | Power BI dashboard |

## 🔄 Project Workflow

1. Collected the Superstore dataset.
2. Checked the dataset structure and data types.
3. Performed data cleaning and preprocessing using Python.
4. Removed duplicate records and checked data quality.
5. Performed exploratory data analysis.
6. Used SQL for business-oriented queries and aggregations.
7. Created an interactive Power BI dashboard.
8. Analyzed the results to identify useful business insights.

## 📈 Power BI Dashboard

The Power BI dashboard provides an interactive view of:

- Total Sales
- Total Quantity
- Net Profit
- Profit Margin
- Region-wise Sales
- Region-wise Profit
- Category-wise Sales
- Discount and Profit Analysis
- Interactive filters

Open `dash.pbix` using **Microsoft Power BI Desktop** to explore the dashboard.

## 🌐 Web Scraping

Web scraping was explored as an additional data collection technique using
Python. The scraped dataset was saved separately as `scraped_data.csv`.

The scraped data was not merged with the Superstore dataset because it had
a different structure and was not required for the final dashboard analysis.
